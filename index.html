vector_to_sentence <- function(vec, oxford_comma = TRUE) {
  n <- length(vec)
  
  if (n == 0) {
    return("")
  } else if (n == 1) {
    return(vec)
  } else if (n == 2) {
    return(paste(vec[1], "et", vec[2]))
  } else {
    comma <- if (oxford_comma) ", et" else " et"
    return(paste(paste(vec[1:(n - 1)], collapse = ", "), comma, vec[n]))
  }
}

À la date du 11/04/25, 15h00, il y a un total de 14716 projets de recherche financés par l’Union Européenne entre 2021 et 2024, tout appel et pays confondus.

Parmis ces projects, 4324 projets (29%) impliquent au moins un participant Français qu’il soit coordinateur ou partenaire, tout projet confondu. De même, 1339 projets (9%) impliquent au moins un participant Irlandais qu’il soit coordinateur ou partenaire, tout projet confondu.

En ce qui concerne la coopération Franco-Irlandaise, 618 projets (4%) impliquent au moins un participant Français et un participant Irlandais, qu’ils soient coordinateurs ou partenaires, tout projet confondu. Cela correspond donc à 14% des projets Français et à 46% des projets Irlandais.

Tendance de Mots-Clés

Tendance de mots clés qui ressortent dans les projets impliquant la France et l’Irlande et observer s’il y a une différence lorsqu’il s’agit de projets coordonnés par l’Irlande ou la France)

À noter

Le traitement des mots clés implique une correspondance exacte entre les différents projets. Cette approche est donc sensible aux différences liées aux pluriels, synonymes, ou bien aux erreurs d’orthographe.

Plutôt que de faire correspondre les mots clés, il est aussi possible d’évaluer la redondance des mots utilisés de manière générale.

Mots-Clés des Projets Coordonnés par un Participant Français et impliquant un partenaire Irlandais

Affiche le code 
df_project_unique <- df |> 
  filter(
    identifiant_de_projet %in% vector_project_id_coord_fr,
    pays == "Irlande"
  ) |> 
  select(identifiant_de_projet, free_keywords) |> 
  distinct()

keyword_counts <- df_project_unique |> 
  drop_na() |> 
  mutate(free_keywords = str_split(free_keywords, ",")) |> 
  unnest(free_keywords) |> 
  mutate(free_keywords = str_trim(free_keywords)) |> 
  count(free_keywords, sort = TRUE)

keyword_counts_vec <- keyword_counts |> 
  count(n) |> 
  mutate(txt = paste(nn, "mots clés sont utilisés", n, "fois"), .keep = "none") |> 
  pull(txt)

Les mots clés utilisés 4 fois sont biodiversity et stakeholder engagement. Les mots clés utilisés 3 fois sont governance, living labs, resilience , et sustainability.

Affiche le code 
keywords <- df_project_unique |> 
  filter(!is.na(free_keywords)) |> 
  mutate(free_keywords = free_keywords |> 
    str_replace_all("[,&]", " ") |> 
    str_replace_all("[^a-zA-Z0-9 ]", "") |> 
    str_to_lower() |> 
    str_split(" ")
  ) |> 
  unnest(free_keywords) |> 
  mutate(free_keywords = str_trim(free_keywords)) |> 
  filter(free_keywords != "") |> 
  anti_join(all_stop_words, by = c("free_keywords" = "word")) |> 
  count(free_keywords, sort = TRUE)

wordcloud(
  words = keywords$free_keywords,
  freq = keywords$n,
  min.freq = 2,
  max.words = 200,
  random.order = FALSE,
  rot.per = 0.25,
  colours = brewer.pal(8, "Dark2")
)
